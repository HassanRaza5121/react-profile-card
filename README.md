# React Profile Card

An interactive, responsive profile card for an AI/ML Engineer, built with **React** and **TypeScript**.

🔗 **Live demo:** https://YOUR-PROJECT.vercel.app

![Screenshot](./screenshot.png)

## Features

- Reusable, typed components (`Avatar`, `SkillList`, `ContactButtons`, `Footer`)
- One-click resume download
- Copy-to-clipboard email button with visual feedback
- Responsive layout and automatic dark mode
- Accessible markup (semantic HTML, keyboard focus styles, reduced-motion support)
- Profile data separated from UI for easy customization

## Tech Stack

React · TypeScript · Vite · CSS (custom properties)

## Getting Started

```bash
git clone https://github.com/YOUR-USERNAME/react-profile-card.git
cd react-profile-card
npm install
npm run dev
```

## Customize

Edit `src/data/profile.ts` with your own details, then replace `public/profile.jpg` and your resume PDF in `public/`.
